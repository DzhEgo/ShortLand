# Настройка запуска сервиса

## Для начала делаем билд докер образа: docker build -t {имя образа}

## После сборки, создайте .env файл, в котором будут указаны переменные: DB_CONN; STORE_TYPE
## DB_CONN - это конфигурация для подключения к БД postgres. Пример: host=? user=? password=? dbname=? port=?
## STORE_TYPE - это выбор, как будет хранятся данные: в базе или in memory. Для использования in memory типа заполнять DB_CONN необязательно

## После создания .env файла создаем контейнер командой: docker run -d -p {порт (8080:8080)} -v {путь до файла .env($(pwd)/.env:/app/.env)} {имя образа}
## В круглых скобках прописаны примеры. В моем случае, чтобы не писать весь путь, я использовал pwd, с учетом того, что я находился в той же самой директории, где и лежит файл .env
