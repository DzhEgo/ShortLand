# Настройка запуска сервиса

## Для начала делаем билд докер образа: docker build -t {имя образа}

## После сборки, создайте .env файл, в котором будут указаны переменные: DB_CONN; STORE_TYPE
## DB_CONN - это конфигурация для подключения к БД postgres. Пример: host=? user=? password=? dbname=? port=?
## STORE_TYPE - это выбор, как будет хранятся данные: в базе или in memory. Для использования in memory типа заполнять DB_CONN необязательно. Параметр принимает: inMemory; inDB. 

## После создания .env файла создаем контейнер командой: docker run -p -e {переменные: DB_CONN и STORE_TYPE} {порт}:8080 {имя образа}
## Если хотим использовать in memory, то можно игнорировать флаг -e. Если хотите использовать базу, то пишем: -e STORE_TYPE=inDB -e DB_CONN="host=? dbname=? user=? password=? port=?"
