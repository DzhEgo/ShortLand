# Настройка запуска сервиса

## Для тестов лучше склонировать репу, создать .env, прописать DB_CONN; STORE_TYPE. Если кофигурация для БД будет пустая, то будут ошибки с выполнением тестов, где тип хранилища будет БД (NewInDB()).

## DB_CONN - это конфигурация для подключения к БД postgres. Пример: host=? user=? password=? dbname=? port=?
## STORE_TYPE - это выбор, как будут хранится данные: в базе или in memory. Для использования in memory можно ничего не заполнять (.env). Параметр принимает: inMemory; inDB.

## Если хотим развернуть, то делаем билд докер образа: docker build -t {имя образа}
## После создания .env файла создаем контейнер командой: docker run -p -e {переменные: DB_CONN и STORE_TYPE} {порт}:8080 {имя образа}
## Если хотим использовать in memory, то можно игнорировать флаг -e. Если хотите использовать базу, то пишем: -e STORE_TYPE=inDB -e DB_CONN="host=? dbname=? user=? password=? port=?"
